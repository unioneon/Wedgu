Wedgu 1.1.0 — Windows 10/11 x64

Run Wedgu.exe. Right-click a widget or the tray icon to open the menu.
Open Settings > About to choose a language. System language is the default;
English is used when the system language is not supported.

Available languages: English, Russian, Spanish, Simplified Chinese, French,
German, Arabic, Portuguese, Japanese, Korean, Italian, Turkish and Hindi.

Weather uses Open-Meteo without an API key (hourly updates). Enter a city or
choose Windows location. IQAir is optional: add your own key in Settings;
air-quality widgets are hidden until a key is provided. Keys are encrypted
by Windows and are not included in this distribution.

Choose Auto for system-colored taskbar/tray widgets and white lock-screen
widgets, or select one shared custom color. Date is off by default.
Battery polling: 1–60 minutes. Lock-screen size: 50–200%, with live preview.

The portable ZIP needs no installation. Settings are still stored in the
Windows user profile; portable and installed copies share these settings.
Keep headsetcontrol.exe alongside Wedgu.exe for supported USB headsets.
SF Pro Display is used if locally installed; the font is not bundled.
Appropriate Windows fonts are used for Arabic, Chinese, Japanese, Korean and Hindi.

Hardware limitations: the tested AJAZZ AK820 Pro reports a percentage over
Bluetooth. Its tested 2.4 GHz receiver supplies no usable battery percentage;
USB reports a marker, not a measured 100%. Other firmware revisions may differ.
A sleeping Lofree Flow Lite84 may need a keypress and a refresh.
