Open-Meteo weather data: https://open-meteo.com/
Weather data attribution: Open-Meteo, CC BY 4.0.
https://creativecommons.org/licenses/by/4.0/
City search: Open-Meteo geocoding API, based on GeoNames data (CC BY 4.0).
https://www.geonames.org/
The public endpoint is intended for non-commercial use; commercial deployments
must comply with Open-Meteo's current service terms and use the appropriate plan.

IQAir data (optional, user-supplied API key): https://www.iqair.com/
US AQI values are supplied by IQAir; custom display icons are visual cues,
not official IQAir health categories. Data access is subject to provider terms.

AccuWeather data (optional, user-supplied API key): https://www.accuweather.com/
Data access is subject to the user's provider plan and terms.

installed locally. Windows fonts provide fallback and additional script coverage.
